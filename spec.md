# Spec: Симулятор ПК (BIOS/UEFI → POST → ОС)

## 1. Цель

Создать правдоподобный интерактивный симулятор ПК в браузере: от UEFI BIOS через POST и загрузчик до «рабочей» операционной системы. Настройки BIOS влияют на модель машины, а модель — на то, как грузится и ведёт себя ОС.

Это имитация, а не эмуляция: настоящий код x86 не исполняется, все устройства, файлы и программы смоделированы.

## 2. Состав

| Компонент      | Что это                                                                                 |
|----------------|-----------------------------------------------------------------------------------------|
| Machine        | общее состояние машины: железо, сохранённые настройки BIOS, сенсоры, логика загрузки    |
| BIOS (UEFI)    | Setup Utility в стиле красно-чёрного геймерского UEFI: EZ Mode и Advanced Mode           |
| POST           | экран самотестирования после выхода из BIOS                                             |
| Boot           | перебор устройств в порядке Boot Priority, ошибки загрузки                               |
| Kestrel OS     | собственная ОС в стиле Windows: загрузка, вход, рабочий стол, окна, приложения           |

**Бренд.** Используем собственные названия и графику: «Kestrel UEFI BIOS», «Kestrel OS». Чужие логотипы, обои, звуки и иконки (MSI, Microsoft и т.д.) не копируем — только узнаваемые паттерны интерфейса.

## 3. Модель машины (Machine)

### 3.1. Состояние

- `hardware` — фейковое железо (только чтение): материнская плата, CPU, DIMM-слоты, накопители по портам.
- `savedConfig` — применённые настройки BIOS (с ними грузится машина).
- `pendingConfig` — изменения в Setup, ещё не сохранённые.
- `sensors` — вычисляются из конфигурации: температуры CPU/MB, Vcore, DRAM V, частоты, обороты вентиляторов, шум.

### 3.2. Описание параметра

| Поле           | Описание                                  |
|----------------|-------------------------------------------|
| `id`           | уникальный ключ                           |
| `label`        | отображаемое название                     |
| `type`         | `toggle` \| `select` \| `number` \| `order` |
| `options`      | варианты для `select`                     |
| `min/max/step` | диапазон для `number`                     |
| `default`      | заводское значение                        |
| `help`         | текст подсказки                           |

### 3.3. Параметры и их последствия

| Параметр              | Значения                                 | Последствие                                                                 |
|-----------------------|------------------------------------------|------------------------------------------------------------------------------|
| Boot Priority         | порядок 5 устройств (drag-and-drop)       | какое устройство грузится первым                                            |
| XMP / EXPO            | Disabled / Profile 1 / Profile 2          | частота, тайминги и напряжение DRAM, немного нагрева                        |
| CPU Core Ratio        | 0 (Auto) … 55                             | частота, Vcore, температура; ≥ 95 °C — POST останавливается                 |
| CPU Fan Profile       | Silent / Standard / Performance / Full    | кривая вентилятора → обороты, температура, шум                              |
| SVM (Virtualization)  | Enabled / Disabled                        | в ОС работают или не работают виртуальные машины                            |
| Secure Boot           | Enabled / Disabled                        | неподписанная флешка с Linux не загрузится                                  |
| Fast Boot             | Enabled / Disabled                        | короткий POST без перечисления устройств                                    |
| LAN Option ROM        | Enabled / Disabled                        | без него сетевая загрузка (PXE) недоступна                                  |
| AHCI / RAID           | AHCI / RAID                               | в RAID ОС не находит загрузочный диск (INACCESSIBLE_BOOT_DEVICE)            |
| HD Audio Controller   | Enabled / Disabled                        | в ОС есть или нет звука                                                     |
| CPU Fan Fail Warning  | Enabled / Disabled                        | предупреждение на POST при остановке вентилятора                            |
| ErP Ready             | Enabled / Disabled                        | энергосбережение в выключенном состоянии (косметика)                        |
| BIOS Log Review       | Enabled / Disabled                        | показывать ли список изменений перед сохранением                            |

### 3.4. Устройства загрузки

| Устройство                     | Поведение                                                    |
|--------------------------------|--------------------------------------------------------------|
| Kestrel OS Boot Manager (NVMe) | загружает Kestrel OS (подписан)                              |
| SATA HDD 2TB                   | данные, не загрузочный                                       |
| DVD-RW                         | диска нет                                                    |
| USB Flash (Live Linux)         | не подписан: блокируется Secure Boot                         |
| PXE Network                    | доступен только при LAN Option ROM; сервера нет → ошибка     |

## 4. BIOS

### 4.1. Общая шапка (в обоих режимах)

- Логотип, переключатель режима **EZ / Advanced (F7)**, кнопки F6 (Defaults), F10 (Save), язык, выход.
- Слева: большие часы, дата, CPU Temp, Motherboard Temp.
- Центр: CPU Speed, DDR Speed, версия BIOS, дата сборки, режим UEFI.
- Справа: модель платы, CPU, объём памяти, Vcore.
- **Boot Priority** — полоса иконок устройств. Порядок меняется перетаскиванием мышью. Отключённые устройства показаны серыми.

### 4.2. EZ Mode

Левое меню и панель содержимого:

| Вкладка   | Содержимое                                                                                       |
|-----------|--------------------------------------------------------------------------------------------------|
| CPU       | большая частота CPU; BCLK, множитель, ядра/потоки, Vcore, SMT, SVM, NX, наборы инструкций          |
| Memory    | большая частота DRAM; переключатель XMP-профиля; тайминги, напряжение, схема DIMM-слотов           |
| Storage   | порты M.2 / SATA / USB с подключёнными устройствами, режим контроллера AHCI/RAID                  |
| Fan Info  | график кривой вентилятора с текущей точкой, выбор профиля, обороты всех вентиляторов, шум          |
| Help      | горячие клавиши и краткая справка по EZ Mode                                                     |

Нижняя часть:
- кнопки **Flash BIOS**, **Favorites**, **Hardware Monitor**;
- сетка плиток-переключателей: LAN Option ROM, HD Audio, CPU Fan Fail Warning, Fast Boot, AHCI/RAID, BIOS Log Review, Secure Boot, SVM, ErP Ready;
- строка подсказки по наведённому элементу.

### 4.3. Advanced Mode (F7)

Классический табличный Setup: Main, Advanced, Boot, Security, Monitor, Save & Exit. Полная навигация с клавиатуры (стрелки, Enter, Esc), справка справа.

### 4.4. Save / Discard

- **F10 / Save & Exit** — подтверждение (со списком изменений, если включён BIOS Log Review), затем POST.
- **Выход без сохранения** — POST с последней сохранённой конфигурацией.
- **Discard Changes** — откат к сохранённому без выхода.
- **F6 / Load Optimized Defaults** — заводские значения (нужно сохранить).
- Несохранённые значения подсвечены, в шапке горит индикатор.

## 5. POST и загрузка

- POST: логотип, CPU, память (с XMP), перечисление устройств (кроме Fast Boot), режим SATA, аудио.
- Проверка перегрева: ≥ 95 °C — остановка.
- Перебор Boot Priority: каждое устройство либо грузится, либо пишет ошибку и система идёт дальше.
- Исходы: Kestrel OS, Live Linux, Secure Boot Violation, INACCESSIBLE_BOOT_DEVICE, No bootable device, перегрев.
- DEL на POST / после ошибки — вход в BIOS.

## 6. Kestrel OS (следующий этап)

- **Загрузка:** логотип со спиннером → экран блокировки → вход → рабочий стол. Fast Boot и частота CPU влияют на длительность.
- **Оболочка:** рабочий стол с иконками, панель задач, меню «Пуск», трей с часами, звуком, сетью, центр уведомлений.
- **Окна:** перетаскивание, изменение размера, свернуть/развернуть/закрыть, фокус, z-order, привязка к краям.
- **Приложения:**
  - Проводник с виртуальной файловой системой (сохраняется в браузере), корзина;
  - Блокнот, Калькулятор;
  - Терминал с командами `dir`, `cd`, `ipconfig`, `systeminfo`, `shutdown`;
  - Диспетчер задач: процессы, загрузка CPU, температура, частота из модели машины;
  - Сведения о системе: CPU, RAM, скорость памяти, режим загрузки, Secure Boot;
  - Виртуальные машины: работают только при включённом SVM;
  - Параметры: обои, тема, звук (недоступен без HD Audio).
- **Сбои:** перегрев под нагрузкой при разгоне → синий экран (своего дизайна) и перезагрузка.
- **Выключение и перезагрузка** возвращают в POST, откуда можно войти в BIOS.

## 7. Технически

- Vite + React + TypeScript, состояние в zustand. Запуск: `npm run dev` (порт 8137).
- Модули: `src/machine` (железо, параметры, сенсоры, загрузка, store), `src/bios`, `src/post`, `src/ui`; дальше — `src/os/*` (оконный менеджер и приложения как плагины).
- Экран — фиксированная сцена 1920×1080, масштабируется целиком под окно.
- Сохранённые настройки BIOS хранятся в localStorage (CMOS), Clear CMOS их стирает.
- Только десктопная версия; мобильная — позже.

## 8. Этапы

1. ✅ Прототип BIOS (табличный).
2. ✅ BIOS в стиле геймерского UEFI: EZ Mode, Advanced Mode, drag-and-drop Boot Priority.
3. ✅ Переезд на Vite + React + TS, общий модуль Machine; сцена 1920×1080; EN/RU; подменю Advanced; инерция температур; редактор кривой вентилятора; CMOS в браузере; POST с DEL/F11, Boot Menu, Boot Override.
4. ⏳ Загрузка Kestrel OS, экран входа.
5. Рабочий стол, оконный менеджер, панель задач, «Пуск».
6. Проводник, Блокнот, Терминал.
7. Диспетчер задач, Сведения о системе, ВМ — связь с BIOS; синий экран.
8. Сценарии «почини систему», несколько конфигураций ПК, мобильная версия.

## 9. Критерии готовности этапа 2

- [ ] EZ Mode: все 5 вкладок содержательные, данные живые.
- [ ] Boot Priority перетаскивается мышью, изменение влияет на загрузку.
- [ ] Все плитки-переключатели работают и подсвечивают несохранённое.
- [ ] Кривая вентилятора меняется при смене профиля, точка двигается с температурой.
- [ ] F7 переключает EZ / Advanced, F6 / F10 / Esc работают.
- [ ] Все исходы загрузки из раздела 5 воспроизводимы.
