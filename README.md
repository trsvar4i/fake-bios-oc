# fake-bios-oc

Симулятор ПК в браузере: от кнопки питания через UEFI BIOS и POST до собственной ОС. Настройки BIOS влияют на модель машины, а та — на то, как грузится и ведёт себя система.

## Что есть

- **Кнопка питания и POST**: логотип, `DEL` — Setup, `F11` — Boot Menu, звуковой сигнал POST.
- **UEFI BIOS** в стиле плат уровня ASUS/MSI/Gigabyte (но со своим брендом Kestrel):
  - EZ Mode: CPU, Memory, Storage, Fan Info, Help; плитки-переключатели; перетаскивание Boot Priority; полная навигация с клавиатуры.
  - Advanced Mode (`F7`): вкладки My Favorites, Main, Tweaker, Advanced, Monitor, Boot, Tool, Security, Exit; подсказка под списком, строка клавиш, живая панель Hardware Monitor справа с графиком температуры.
  - Tweaker: множитель, BCLK, PBO, LLC, порог троттлинга, Vcore и DRAM Voltage с подсказкой «нужное напряжение», частота и тайминги памяти (tCL/tRCD/tRP/tRAS).
  - Monitor: графики температуры и оборотов за 90 секунд, напряжения, Q-Fan с редактором кривой и режимом корпусных вентиляторов.
  - Tool: Kestrel Instant Flash (обновление с флешки с прогрессом), OC Profiles (6 слотов), SPD, ссылка на конфигурацию.
  - Security: пароль администратора на вход в Setup (сбрасывается Clear CMOS), Secure Boot, TPM. Boot: Launch CSM, порядок, Boot Override.
  - Плавная тепловая модель, напряжения, нестабильность разгона и «Overclocking Failed».
  - EN / RU, настройки сохраняются в браузере (CMOS).
- **Звук** (Web Audio, без сэмплов): щелчок питания, HDD, DVD, PC speaker, сирена перегрева, звуки ОС. Постоянного шума нет.
- **Исходы загрузки**: ОС, Live Linux, Secure Boot Violation, INACCESSIBLE_BOOT_DEVICE, перегрев, нет загрузочного устройства, ошибка разгона, падение ОС при нестабильном разгоне.
- **Kestrel OS** — собственный язык интерфейса, не похожий ни на macOS, ни на Windows: минимализм и плавные пружинные анимации.
  - «Насест» (Perch) — одна парящая панель внизу: кнопка «Гнезда», закреплённые и запущенные программы (активная раскрывается в «пилюлю» с названием), Корзина, рабочие столы, статус и время.
  - «Хаб» (Alt+H) справа: быстрые плитки (сеть, «Не беспокоить», ночной свет, тема), яркость и громкость, режим питания, музыка, таймер, уведомления.
  - «Гнездо» (Alt+L): все программы по разделам, учётная запись и питание. «Бросок» (Alt+Space): командная палитра — программы, файлы, вычисления, команды системы.
  - Окна: тонкая рамка, заголовок слева, «пилюля» управления справа (меню окна, свернуть, развернуть, закрыть), полоска акцента у активного окна. «Все окна» (Alt+↑), переключатель программ (Alt+`), рабочие столы (Alt+←/→), Alt+D — показать стол.
  - Иконки — плитки со срезанным углом (грань шестиугольника из логотипа); шрифт Manrope; светлая/тёмная/авто тема, ночной свет, облегчённый режим и «меньше движения».
  Приложения: Файлы, Редактор, Заметки (файлы в ~/Notes), Напоминания, Календарь, Калькулятор, Часы, Браузер, Терминал (zsh), Мониторинг, Kestrel VM (гостевой Linux и Kestrel внутри окна), Настройки, Магазин, Обслуживание, Испытания; из Магазина ставятся Рисовалка, Просмотр и Музыка.
- **Испытания**: 17 целей — разогнать до 5 ГГц, перегреть, загрузить Live Linux, получить Secure Boot Violation, обновить прошивку, запустить VM… Прогресс в браузере, тост поверх любого экрана.
- **Ссылка на конфигурацию**: BIOS → Tool → Share Configuration копирует ссылку `#cfg=…`; открывший её получает предложение применить настройки.
- **Связь железа и системы**: открытые программы и `stress` в Терминале нагружают процессор — растут температура и обороты; при перегреве частота сбрасывается и приходит уведомление. Режимы питания (Тихий / Баланс / Мощность) меняют частоту. Без сетевой карты в BIOS Магазин офлайн, без HD Audio нет звука и музыки.
- **Сбой и восстановление**: при падении от разгона можно сбросить множитель и напряжение одной кнопкой. **Обновление прошивки** из «Системных настроек»: загрузка, экран прошивки, новая версия в POST, BIOS и ОС.
- **Несколько рабочих столов** (Alt+←/→, Alt+1…6), **несколько пользователей** со своими файлами и настройками, имя компьютера, язык (общий с BIOS), 12/24-часовой формат.
- **Первый запуск**: знакомство на экране питания и приветствие в системе. **Телефоны**: подсказка повернуть экран, экранные клавиши DEL/F11/F7/F10/Esc, долгое нажатие вместо правой кнопки, полный экран.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:8137. Сборка: `npm run build`, тесты: `npm test`.

Онлайн: https://trsvar4i.github.io/fake-bios-oc/ — собирается и выкладывается GitHub Actions при каждом пуше в `main` (`.github/workflows/pages.yml`).

## Структура

```
src/
├── main.tsx, App.tsx, app.css   точка входа: экран 1920×1080, переключение питание → BIOS → ОС
├── machine/                     общее: модель ПК, настройки, сенсоры, загрузка, звук
├── bios/                        BIOS: питание, POST, Setup (EZ / Advanced)
│   ├── post/
│   ├── setup/
│   └── ui/
└── os/                          Kestrel OS: экраны, рабочий стол, окна
    └── apps/                    приложения ОС
docs/
├── spec.md                      общая спецификация симулятора
└── os-design.md                 концепция ОС
```

В каждой из папок `machine`, `bios`, `os` есть свой README с описанием файлов.

Стек: Vite, React, TypeScript, zustand.
