# fake-bios-oc

Симулятор ПК в браузере: от кнопки питания через UEFI BIOS и POST до собственной ОС. Настройки BIOS влияют на модель машины, а та — на то, как грузится и ведёт себя система.

## Что есть

- **Кнопка питания и POST**: логотип, `DEL` — Setup, `F11` — Boot Menu, звуковой сигнал POST.
- **UEFI BIOS** в стиле геймерских плат:
  - EZ Mode: CPU, Memory, Storage, Fan Info, Help; плитки-переключатели; перетаскивание Boot Priority; полная навигация с клавиатуры.
  - Advanced Mode (`F7`): вкладки с подменю, около 30 параметров, зависимости между ними, Boot Override, Clear CMOS.
  - Редактор кривой вентилятора, плавная тепловая модель, напряжения, нестабильность разгона и «Overclocking Failed».
  - EN / RU, настройки сохраняются в браузере (CMOS).
- **Звук** (Web Audio, без сэмплов): вентиляторы по оборотам, HDD, DVD, PC speaker, сирена перегрева.
- **Исходы загрузки**: ОС, Live Linux, Secure Boot Violation, INACCESSIBLE_BOOT_DEVICE, перегрев, нет загрузочного устройства, ошибка разгона, падение ОС при нестабильном разгоне.
- **Kestrel OS** (в разработке): загрузка, экран входа, окна, приложения, связанные с BIOS.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:8137. Сборка: `npm run build`.

## Структура

- `src/machine` — модель ПК: железо, параметры BIOS, сенсоры, логика загрузки, общее состояние.
- `src/bios` — интерфейс BIOS.
- `src/post` — питание, POST, экран загрузки.
- `src/os` — Kestrel OS.
- `src/audio` — синтез звуков.
- `spec.md` — общая спецификация, `docs/os-design.md` — концепция ОС.

Стек: Vite, React, TypeScript, zustand.
