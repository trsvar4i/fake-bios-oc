# fake-bios-oc

Симулятор ПК в браузере: от кнопки питания через UEFI BIOS и POST до собственной ОС. Настройки BIOS влияют на модель машины, а та — на то, как грузится и ведёт себя система.

## Что есть

- **Кнопка питания и POST**: логотип, `DEL` — Setup, `F11` — Boot Menu, звуковой сигнал POST.
- **UEFI BIOS** в стиле геймерских плат:
  - EZ Mode: CPU, Memory, Storage, Fan Info, Help; плитки-переключатели; перетаскивание Boot Priority; полная навигация с клавиатуры.
  - Advanced Mode (`F7`): вкладки с подменю, около 30 параметров, зависимости между ними, Boot Override, Clear CMOS.
  - Редактор кривой вентилятора, плавная тепловая модель, напряжения, нестабильность разгона и «Overclocking Failed».
  - EN / RU, настройки сохраняются в браузере (CMOS).
- **Звук** (Web Audio, без сэмплов): щелчок питания, HDD, DVD, PC speaker, сирена перегрева, звуки ОС. Постоянного шума нет.
- **Исходы загрузки**: ОС, Live Linux, Secure Boot Violation, INACCESSIBLE_BOOT_DEVICE, перегрев, нет загрузочного устройства, ошибка разгона, падение ОС при нестабильном разгоне.
- **Kestrel OS** — основа macOS со своим почерком: три «островка» сверху (центральный показывает таймер и уведомления), док с плавным увеличением, «Все окна» (⌥↑), переключатель программ (⌥`), центр уведомлений, светлая/тёмная/авто тема, виджеты, Launchpad, Spotlight, перетаскивание файлов.
  Приложения: Finder, TextEdit, Заметки, Напоминания, Календарь, Калькулятор, Часы, Терминал (zsh), Мониторинг системы, Kestrel VM, Системные настройки, Магазин, Обслуживание; из Магазина ставятся Рисовалка, Просмотр и Музыка. Файлы общие для Finder, Терминала и рабочего стола.
- **Связь железа и системы**: открытые программы и `stress` в Терминале нагружают процессор — растут температура и обороты; при перегреве частота сбрасывается и приходит уведомление. Режимы питания (Тихий / Баланс / Мощность) меняют частоту. Без сетевой карты в BIOS Магазин офлайн, без HD Audio нет звука и музыки.
- **Сбой и восстановление**: при падении от разгона можно сбросить множитель и напряжение одной кнопкой. **Обновление прошивки** из «Системных настроек»: загрузка, экран прошивки, новая версия в POST, BIOS и ОС.
- **Несколько рабочих столов** (⌥←/→, ⌥1…6), **несколько пользователей** со своими файлами и настройками, имя компьютера, язык (общий с BIOS), 12/24-часовой формат.
- **Первый запуск**: знакомство на экране питания и приветствие в системе. **Телефоны**: подсказка повернуть экран, экранные клавиши DEL/F11/F7/F10/Esc, долгое нажатие вместо правой кнопки, полный экран.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:8137. Сборка: `npm run build`, тесты: `npm test`.

Онлайн: https://trsvar4i.github.io/fake-bios-oc/ — собирается и выкладывается GitHub Actions при каждом пуше в `main` (`.github/workflows/pages.yml`).

## Структура

```
src/
├── main.tsx, App.tsx, app.css   точка входа: экран 1920×1080, переключение питание → BIOS → ОС
├── machine/                     общее: модель ПК, настройки, сенсоры, загрузка, звук
├── bios/                        BIOS: питание, POST, Setup (EZ / Advanced)
│   ├── post/
│   ├── setup/
│   └── ui/
└── os/                          Kestrel OS: экраны, рабочий стол, окна
    └── apps/                    приложения ОС
docs/
├── spec.md                      общая спецификация симулятора
└── os-design.md                 концепция ОС
```

В каждой из папок `machine`, `bios`, `os` есть свой README с описанием файлов.

Стек: Vite, React, TypeScript, zustand.
