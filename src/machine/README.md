# Machine (общая модель ПК)

Общее для BIOS и ОС: «железо» и его состояние. Без интерфейса.

| Файл | Что внутри |
|---|---|
| `hardware.ts` | плата, процессор, память, накопители, устройства загрузки, профили XMP и вентиляторов |
| `params.ts` | все параметры BIOS: значения по умолчанию, подсказки, зависимости |
| `sensors.ts` | температура, обороты, напряжения, стабильность разгона |
| `boot.ts` | сценарий POST и итог загрузки |
| `store.ts` | общее состояние: фаза (питание → POST → BIOS → ОС), настройки, CMOS |
| `audio.ts` | синтез звуков ПК: вентиляторы, диски, PC speaker, звуки ОС |
| `i18n.ts` | двуязычные строки |
