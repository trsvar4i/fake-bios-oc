# Kestrel OS (операционная система)

Всё, что видно после успешной загрузки. Концепция — `docs/os-design.md`.

| Папка / файл | Что внутри |
|---|---|
| `Os.tsx` | корень ОС: переключает экраны загрузки, входа, рабочего стола |
| `Screens.tsx` | загрузка, экран блокировки, критическая ошибка, выключение |
| `Desktop.tsx` | рабочий стол: обои, виджеты, диск и файлы рабочего стола, окна; правая кнопка — только на пустом столе, файлах, виджетах и в доке |
| `Wallpaper.tsx`, `wallpapers.ts` | обои из волн: одна композиция в шести цветах, от них — акцент и оттенок стекла |
| `Widgets.tsx` | виджеты (часы, календарь, напоминания, состояние ПК, заметки) и их галерея |
| `Menus.tsx` | общий вид меню и слой контекстного меню |
| `commands.ts` | команды для меню и горячих клавиш (⌥ = Alt) |
| `fs.ts` | файлы пользователя: общие для Finder, TextEdit, Терминала и рабочего стола; Корзина |
| `MenuBar.tsx` | три «островка»: меню, динамический центр (часы, таймер, уведомления), статус; пункт и центр уведомлений |
| `Dock.tsx` | док: плавное увеличение (requestAnimationFrame), закреплённые и запущенные приложения, Корзина, меню иконок |
| `Overlays.tsx` | Launchpad, Spotlight (Ctrl+Space, ищет и файлы), «О программе», сочетания клавиш, «Все окна», переключатель программ |
| `load.ts` | нагрузка на процессор от программ и `stress`, режим питания, уведомление о перегреве |
| `music.ts` | синтезатор и плеер для «Музыки» (Web Audio) |
| `users.ts` | учётные записи: у каждого свои настройки и файлы |
| `apps/*.css` | стили каждого приложения рядом с его кодом |
| `ui.test.tsx` | тесты интерфейса в jsdom: Калькулятор, Терминал (в т. ч. StrictMode), Магазин |
| `os.test.ts` | тесты: файловая система, калькулятор, раскладка «Все окна» (`npm test`) |
| `Window.tsx` | окно в стиле macOS: «светофор», прилипание с подсказкой, анимации открытия, закрытия и сворачивания в док |
| `osStore.ts` | состояние ОС: окна, экран, настройки пользователя |
| `power.ts` | выключение, перезагрузка (в том числе в BIOS), системные звуки |
| `AppIcon.tsx` | иконки приложений и логотип ОС |
| `apps/` | приложения; `meta.ts` — список, `index.ts` — регистрация |
| `os.css` | стили ОС |

ОС читает сохранённые настройки BIOS из `src/machine` (виртуализация, звук, сеть, частоты) — так BIOS влияет на поведение системы.
