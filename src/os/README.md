# Kestrel OS (операционная система)

Всё, что видно после успешной загрузки. Концепция — `docs/os-design.md`.

| Папка / файл | Что внутри |
|---|---|
| `Os.tsx` | корень ОС: переключает экраны загрузки, входа, рабочего стола |
| `Screens.tsx` | загрузка, экран блокировки, критическая ошибка, выключение |
| `Desktop.tsx` | рабочий стол и системные панели |
| `Window.tsx` | окно: перетаскивание, прилипание, размер, кнопки |
| `osStore.ts` | состояние ОС: окна, экран, настройки пользователя |
| `power.ts` | выключение, перезагрузка (в том числе в BIOS), системные звуки |
| `AppIcon.tsx` | иконки приложений и логотип ОС |
| `apps/` | приложения; `meta.ts` — список, `index.ts` — регистрация |
| `os.css` | стили ОС |

ОС читает сохранённые настройки BIOS из `src/machine` (виртуализация, звук, сеть, частоты) — так BIOS влияет на поведение системы.
